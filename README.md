# Vipul Singh — SRE Portfolio

Responsive static portfolio built with plain HTML, CSS, and JavaScript. No build tools or external libraries required.

## Preview
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a repository (for example, `vipul-portfolio`) and upload `index.html` to its root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

For a user-site URL such as `https://ermvipul.github.io/`, the repository must be named `ermvipul.github.io`. A regular repository name publishes at `https://ermvipul.github.io/<repository-name>/`.
